AURA — AI-Powered Environmental Awareness and Navigation Assistant

About the Project

AURA (AI-Powered Environmental Awareness and Navigation Assistant) is an AI-based assistive application designed to help visually impaired people understand their surroundings and navigate unfamiliar environments more confidently.

The application uses a smartphone camera, artificial intelligence, and voice interaction to describe nearby objects and provide audio-based environmental awareness.

Problem Statement

Visually impaired individuals may face difficulties identifying obstacles, understanding unfamiliar surroundings, and moving independently in new environments. AURA aims to make environmental information more accessible through AI-powered visual assistance and voice interaction.

Key Features

- AI-Powered Scene Understanding: Analyzes camera images to describe the user's surroundings.
- Voice Assistance: Enables users to interact with the application using voice commands.
- Audio Descriptions: Provides spoken descriptions of visual information.
- Camera Integration: Uses the device camera to capture the surrounding environment.
- Backend AI Processing: Sends captured images to a backend for AI-based analysis.
- Accessible Interface: Designed with a focus on simplicity and accessibility.

How It Works

1. The user opens the AURA application.
2. The user grants camera and microphone permissions.
3. The camera captures an image of the surroundings.
4. The image is sent to the backend for AI analysis.
5. The AI generates a description of the scene.
6. The application communicates the result through voice output.

Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python
- AI Integration: OpenAI API
- Backend Server: Flask/Gunicorn, depending on the configured application
- Version Control: Git and GitHub
- Deployment: Vercel for the frontend and Render for the backend

Project Objective

To develop an accessible AI-powered assistant that helps visually impaired individuals gain better awareness of their surroundings through camera-based scene understanding and voice interaction.

Future Enhancements

- Real-time obstacle detection
- Object and text recognition
- Navigation assistance
- Multilingual voice support
- Emergency assistance features

Important Safety Note

AURA is a prototype intended to support environmental awareness. It should not be relied upon as the sole method of navigation or obstacle avoidance. AI-generated descriptions may be inaccurate, so users should continue to use established mobility aids and assistance where appropriate.
